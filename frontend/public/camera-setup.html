Before you start
How it works
💡
Your CCTV cameras are on your local factory network. SafeguardsIQ runs on the cloud. To connect them, you run a small program called the SafeguardsIQ Agent on any Windows PC inside your factory. It acts as the bridge — reading camera frames and sending them to the AI.
📹

Your CCTV camera

Any IP camera with RTSP support — Hikvision, Dahua, CP Plus, etc.

💻

SafeguardsIQ Agent (runs on factory PC)

Connects to camera on local network, captures a frame every 15 seconds, sends to cloud AI

🤖

SafeguardsIQ AI (cloud)

Claude Vision analyses the frame for PPE violations, pathway breaches, unsafe acts

📱

Alert sent within 28 seconds

WhatsApp alert to supervisor + violation saved to your compliance dashboard

Your zones appear on the left

Step 02
2 Add your cameras in the dashboard
Register each camera with its label, IP address, and RTSP URL.
1

Click "+ Add Camera"

On the Settings → Cameras page, click the orange button. A new camera form opens under the zone you select.

2

Fill in the camera details

These are the fields you need to fill:

Field What to enter Example
Camera ID / Label A short name for this camera. Must be unique. This label links the camera to AI detections. CAM-01
Location Description Where the camera is mounted — for your own records. North wall, Welding Bay, 4m height
IP Address The camera's IP address on your local network. 192.168.1.101
Port Almost always 554 for RTSP. Leave as default unless your camera uses a different port. 554
Username Camera login username. Default is usually "admin". admin
Password Camera login password. Set this when you first configured your camera. camera123
RTSP URL Auto-filled from IP/port/username/password. You can also paste it directly if you know it. rtsp://admin:camera123@192.168.1.101:554/stream1
PPE Detection Rules Toggle which items to detect — Hard Hat, Safety Vest, Gloves, etc. Only selected items trigger alerts. Hard Hat ✓, Safety Vest ✓
3

Click "Add Camera"

The camera is saved to your account. Repeat for each camera.

💡
Important: The Camera ID you enter here (e.g. CAM-01) must exactly match what you enter in the relay agent in Step 5. This is how the system links AI detections to the right camera and zone.
Step 03
3 Find your camera's RTSP URL
The RTSP URL is your camera's stream address. Here's how to find it.
RTSP URL Format
rtsp:// admin : your_password @ 192.168.1.101 : 554 /stream1
Protocol Username Password Camera IP Port Stream path
RTSP URLs by brand
BrandRTSP URL
Hikvisionrtsp://admin:PASSWORD@IP:554/Streaming/Channels/101
Dahuartsp://admin:PASSWORD@IP:554/cam/realmonitor?channel=1&subtype=0
CP Plusrtsp://admin:PASSWORD@IP:554/stream1
Bosch / Axisrtsp://admin:PASSWORD@IP:554/axis-media/media.amp
Generic / ONVIFrtsp://admin:PASSWORD@IP:554/stream1
✅
Test your RTSP URL first — open VLC on any PC → Media → Open Network Stream → paste the URL. If video plays in VLC, it will work with SafeguardsIQ.
🔍
How to find your camera's IP address: Log in to your router and look at connected devices. Or check the sticker on the camera body. Most cameras default to 192.168.1.x. You can also use the camera's own setup software (e.g. Hikvision iVMS-4200, Dahua ConfigTool) to find it.
Step 04
4 Install the SafeguardsIQ Agent
Install this once on any Windows PC that is connected to the same network as your cameras. The PC can be a spare desktop, a laptop, or any always-on machine.
1

Install Python 3.11 (if not already installed)

Go to python.org/downloads → Download Python 3.11 or newer → Run installer

⚠️
Important: During installation, tick the checkbox "Add Python to PATH" before clicking Install. Without this, the agent will not run.
2

Download the SafeguardsIQ Agent

Download safeguardsiq_agent.py from your SafeguardsIQ dashboard under Settings → Cameras → Download Agent, and save it to your Desktop.

3

Install required packages

Open Command Prompt (search "cmd" in Start menu) and run:

# Install required Python packages (one time only)
pip install opencv-python requests

This takes 2-3 minutes to download and install. You only need to do this once.

Step 07 — Optional but recommended
7 Auto-start on PC boot
Make the agent start automatically every time the PC turns on so monitoring never stops.
1

Open the Windows Startup folder

Press Win + R, type shell:startup, press Enter. A folder opens.

2

Create a new file called safeguardsiq.bat

Right-click in the folder → New → Text Document → rename to safeguardsiq.bat

3

Paste this content and save

@echo off
rem SafeguardsIQ Auto-Start — edit the lines below with your details

set SAFEGUARDSIQ_EMAIL=suresh@yourfactory.com
set SAFEGUARDSIQ_PASSWORD=yourpassword
set CAMERA_1_LABEL=CAM-01
set CAMERA_1=rtsp://admin:pass@192.168.1.101:554/stream1
set CAMERA_2_LABEL=CAM-02
set CAMERA_2=rtsp://admin:pass@192.168.1.102:554/stream1

python C:\Users\YourName\Desktop\safeguardsiq_agent.py safeguardsiq.bat

Replace the email, password, camera labels, RTSP URLs, and file path with your actual details.

💡
The agent will now start automatically every time this PC boots — no manual action needed. Monitoring is always on.
Step 08
Troubleshooting
❌ "Cannot connect" — retrying

The agent cannot reach the camera's RTSP stream. Check:
1. Is the camera's IP address correct? Try pinging it: ping 192.168.1.101 in Command Prompt
2. Is the camera on the same network as the PC running the agent?
3. Is the RTSP URL correct? Test it in VLC first.
4. Is the camera's password correct? Check username/password in camera settings.

❌ Login failed — Invalid email or password

Double-check your SafeguardsIQ email and password. Make sure you're using the same credentials as safeguardsiq.com. If you forgot your password, use Forgot Password on the login page — a reset link will be sent to your WhatsApp.

❌ Violations not appearing in dashboard

1. Check the camera label in the agent matches exactly what's in Settings → Cameras (e.g. both must be CAM-01 — not CAM-1 or cam-01)
2. Check the agent terminal — are violations being detected? (🚨 lines)
3. Check your internet connection on the factory PC

❌ No WhatsApp alerts

1. Go to safeguardsiq.com → Settings → Profile and verify your WhatsApp number is saved (with country code, e.g. +91 98765 43210)
2. Make sure WhatsApp alerts are enabled in Settings → Notifications
3. The first alert requires you to have messaged our WhatsApp number at least once. Send "Hi" to +91 96744 08408 on WhatsApp to activate.

❌ "pip is not recognized" error

Python was not added to PATH during installation. Uninstall Python, reinstall it, and tick "Add Python to PATH" on the first screen before clicking Install.

⚠️ Camera shows "error" status in dashboard

This usually means the RTSP URL or password in Settings → Cameras is wrong. Go to Settings → Cameras → edit the camera → fix the IP, username, password, or RTSP URL → save → restart the agent.
